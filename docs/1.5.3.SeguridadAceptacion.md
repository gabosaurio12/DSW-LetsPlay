
# Aceptación de Seguridad

## Manejo de secretos

- Las credenciales de `database/roles.sql` son solo de demostración y deben reemplazarse antes de cualquier despliegue.
- Las credenciales reales, tokens y claves deben mantenerse fuera del repositorio, en el mecanismo de configuración que se defina para el despliegue.
- Esta documentación no debe incluir valores reales de credenciales, tokens ni datos personales.
